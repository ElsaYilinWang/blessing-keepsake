# Privacy and consent practice
- Ask each identifiable person for permission to use their photo, transform it with the chosen tool,
  and print it. Agree separately on sharing, portfolio use and commercial use.
- Explain any upstream tool's uploads and retention before using it. The layout engine itself runs offline.
- Keep originals, illustrations, private configs and exports in ignored private/ and exports/ folders.
  Ignore rules are convenience, not access control or a guarantee against accidental publication.
- Obtain appropriate permission for children's images from their parent/guardian and respect their wishes.
- The renderer creates new RGB output and does not copy source EXIF/GPS metadata. Names and dates
  deliberately rendered onto a card remain visible personal information.
- Store files securely, agree a retention/deletion date, and remove unneeded references and model caches.
- Before Git publication inspect staged files and history. If a private file was already committed,
  adding it to .gitignore does not remove it from history.
- Use only photos, artwork and fonts you have permission to use. These are project practices,
  not a substitute for checking obligations relevant to your use.
