# Repeatable keepsake workflow
1. Intake: choose Portrait Keepsake (one photo) or Four Memories (four moments); collect names,
   relationship, occasion, blessing, separate context sentence, optional place/date, and consent.
2. Record identity, moment and story details in must_preserve. Include each person's expression,
   hairstyle, pose and meaningful objects. Decide what may be simplified.
3. Create illustrations upstream using docs/UPSTREAM.md. Keep versions private.
4. Review likeness and details against the originals; request targeted corrections.
5. Copy a template to private/, supply local illustration paths, edit text, and render.
6. Check preview at normal reading size. Verify all text, all four memories if applicable,
   face visibility, crop, and safe margins. Review flags record human decisions only.
7. Print one 10x15 test. Ask the printer for no auto-enhancement and inspect its crop preview.
   Keep a little extra room if the printer trims more than expected.
8. Deliver the intended files privately; retain or delete working files as agreed.

## Working estimates, not measured benchmarks
Allow roughly 5-10 minutes for intake, 10-30 minutes per upstream illustration including review,
5-10 minutes for wording/layout, and 5-10 minutes for final checks. Four memories and difficult
likeness corrections can take substantially longer. Local export typically takes seconds on a
modern computer; measure your own device. Printing/collection time is additional.

Core layout has no per-export service charge. Budget separately for your time, optional upstream
generation attempts, print-shop price and frame/postage. Cost = labour hours × your rate +
generation charges + prints + frame/postage. No current provider prices or shop availability are assumed.
